# Simple Finance India 🇮🇳

**File your ITR-4 in minutes, not hours.**

Built for self-employed professionals, tutors, coaches, and freelancers using Section 44AD presumptive taxation.

## How to put this LIVE online (free, 5 minutes)

### Step 1 — Create a GitHub account
1. Go to github.com
2. Click "Sign up" — it's free
3. Create your account

### Step 2 — Upload this code to GitHub
1. Click "New repository" on GitHub
2. Name it: simple-finance-india
3. Upload all these files

### Step 3 — Deploy on Vercel (free hosting)
1. Go to vercel.com
2. Sign up with your GitHub account
3. Click "Import project" → select simple-finance-india
4. Click "Deploy" — done!

Your site will be live at: https://simple-finance-india.vercel.app

### Step 4 — Get a custom domain (optional)
Buy simplefinanceindia.com from GoDaddy or Namecheap (~₹800/year)
Add it in Vercel settings → Domains

## Features
- Homepage with pricing
- User registration & login
- Income entry management (add, edit, delete)
- Section 44AD tax calculation (fully accurate)
- ITR-4 form with auto-fill
- Downloadable ITR summary
- Works on mobile, tablet, desktop

## Tech Stack
- React 18
- Vite
- localStorage (for data persistence)
